## Wire into the project

<ServerlessConfigTabs>
  <ServerlessConfigYaml>
```yaml title="serverless.yml"
plugins:
  - '@interlace/serverless-api-gateway-caching'

custom:
  interlaceCaching:
    enabled: true
    clusterSize: '0.5'
    ttlInSeconds: 300
```
  </ServerlessConfigYaml>
  <ServerlessConfigTypescript>
```ts title="serverless.ts"
const serverlessConfiguration = {
  plugins: ['@interlace/serverless-api-gateway-caching'],
  custom: {
    interlaceCaching: {
      enabled: true,
      clusterSize: '0.5',
      ttlInSeconds: 300,
    },
  },
};
```
  </ServerlessConfigTypescript>
  <ServerlessConfigJavascript>
```js title="serverless.js"
module.exports = {

  },
};
```
  </ServerlessConfigJavascript>

## Smoke test

The dry-run command verifies the plugin registered and your config parses, without touching AWS:

```bash
sls caching preview
```

Expected output: a `Caching plan` block listing each `http`-event endpoint and the patch operations a deploy would apply.
