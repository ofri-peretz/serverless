## Overview

`@interlace/serverless-iam-roles-per-function` is a TypeScript-native replacement for [`serverless-iam-roles-per-function`](https://www.npmjs.com/package/serverless-iam-roles-per-function) (community v3.2.0, last published 2021-05-21). It keeps the same config keys for drop-in compatibility, adds first-class TypeScript config types, four CLI commands the community plugin lacks, EventBridge + S3 auto-permissions, and strict statement validation. Supports Serverless Framework v3 and v4.
